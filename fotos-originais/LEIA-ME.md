# Fotografias originais

Coloque aqui as fotos em alta resolução da Sofia (JPG, PNG, WebP ou TIFF).

- Numere os arquivos na ordem da galeria (`fotografia1`, `fotografia2`…). Quem define a ordem no site é a lista em `src/content/gallery.ts`.
- Rode `npm run photos`: as versões otimizadas (AVIF/WebP/JPG, sem metadados de GPS) são geradas em `public/fotos/`.
- Cole a lista impressa no terminal em `src/content/gallery.ts` e escreva um texto alternativo (`alt`) para cada foto.

Os arquivos desta pasta **não** são publicados nem versionados (veja `.gitignore`).
